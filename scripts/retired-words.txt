# Retired words (scripts/check-vocabulary.sh): "<word> [<allowed hit regex>]".
# A hit is "path:line:text"; the regex must match it from the start.
#
# "provider" — one word: plugin. Allowed: xterm's own "link provider" API.
provider .*[Ll]ink [Pp]rovider|.*registerLinkProvider
providers
# "loadout" — the compiled-in plugin set of a leaf binary.
loadout
# "viewX"/"viewY" — a doorway's integer window origin, spelled ViewX/ViewY on
# the wire and viewX/viewY in proto-JSON. Schema v11 keeps the framing as a
# float center (viewCx/viewCy), and nothing on the wire answers to the old
# name, so a stale read is silently undefined. The SQL column view_x is a
# different word and stays legal: the migration shim must still spell it.
viewX
viewY
# "federation" — two words for the edge is one too many: a node connects to a
# node over a connection, through the connection door. The word survives only
# where a home already has it written down — the server.yaml `federation:`
# key, the <home>/federation.sock socket file, and the serving banner's
# federation= field — so it is allowed in internal/config, which owns the key,
# and on any line that spells the socket file or the banner field.
federation internal/config/|.*federation\.sock|.*federation=|.*`federation|.*cfg\.Federation|.*config\.FederationSocket
# "launcher" — a well onto a place is a doorway, the word the + menu, the
# crumbs and client/door already use; "launcher" named the same tile and said
# nothing more. Allowed for the shadow launchers, the browser-opening scripts a
# shell's PATH points at, which are a different thing.
launcher internal/local/tmux/|internal/local/shellsvc/
