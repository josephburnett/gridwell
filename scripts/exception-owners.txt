# Exception fields and their owners (scripts/check-exception-owners.sh):
# "<field regex> <allowed path regex>". The field may be read only inside the
# paths listed; everywhere else the question goes through the owner's
# predicate. A hit is "path:line:text" and the regex must match it from the
# start. Comment lines in the scanned files are not hits — naming a field in
# prose is not reading it.
#
# serves_page: rpc.Tile.WebContent / TextDocument / PageContent own the
# derivation. client/textedit reads the answer, not the field, so it is here
# only for the wire type it re-exports. url_preview keys a preview blob on
# serves_page alone on purpose: any page-serving row wants that key, url tile
# or not.
\.ServesPage\b api/rpc/|client/textedit/|client/wasm/url_preview\.go
# text_presentation: the faces a text tile has. textedit.ToggleVisible (which
# faces exist) and textedit.PresentationHTML (which renderer draws one) are its
# two owners, in a package `make check` executes.
\.TextPresentation\b api/rpc/|client/textedit/
# link_target_id: rpc.Tile.ContentID resolves it, rpc.Tile.LeafLink asks
# whether there is one, deadref reads it to name a dead namespace.
\.LinkTargetID\b api/rpc/|client/deadref/
# reference: isLinkTile draws it, deadref classifies it, pluginhealth's
# UnrootedLink is the launcher precondition.
\.Reference\b api/rpc/|client/deadref/|client/pluginhealth/|client/wasm/render\.go
# The two grid-wide declarations. cache.Grid owns both, nil-safe.
Meta\.HostContent\b client/cache/
Meta\.Stale\b client/cache/
# writable: a.gridWritable / a.gridKnownReadOnly, the two safe defaults for
# one uncached grid (Q7 folds them into one tri-state).
Meta\.Writable\b client/cache/|client/wasm/plugin_id\.go
